# ElectroStore FAQ Chatbot

Ứng dụng demo chatbot hỏi đáp cho cửa hàng điện tử ElectroStore. Bot sử dụng thuật toán TF-IDF tự triển khai để vector hóa câu hỏi, lưu trữ lên ChromaDB và truy vấn lại qua giao diện Streamlit.

## Yêu cầu

- Python 3.10+
- Pip

## Cài đặt

```bash
pip install -r requirements.txt
```

## Chạy ứng dụng

```bash
streamlit run app.py
```

Sau khi chạy, mở trình duyệt theo địa chỉ Streamlit cung cấp (mặc định: http://localhost:8501) và bắt đầu trò chuyện với chatbot.
